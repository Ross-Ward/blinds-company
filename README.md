# 🏠 Dublin City Blinds - Premium Landing Page

A high-end, modern landing page for a bespoke window treatment business based in Dublin, Ireland. Featuring a luxury aesthetic, interactive product galleries, and a mobile-responsive design.

## ✨ Features

- **Luxury Hero Section**: Immersive visual introduction with glassmorphism and smooth animations.
- **Product Gallery**: Detailed showcase of Roman Blinds, Wood Venetians, and Electric Rollers.
- **Service Highlights**: Quick overview of core value propositions (Quality, Custom Fit, Protection).
- **Responsive Navigation**: Seamless experience across desktop and mobile devices.
- **Modern Animations**: Powered by Framer Motion for a premium user experience.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel Ready

## 📦 Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm run dev
   ```

3. **Visit the Site**
   Navigate to `http://localhost:3000`.
